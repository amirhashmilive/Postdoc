# Glossary

## Project-Specific Terms

| Term | Definition |
|------|-----------|
| **CSR** | Corporate Social Responsibility — corporate practices aimed at social betterment |
| **ESG** | Environmental, Social, and Governance — framework for evaluating corporate sustainability |
| **Five-Pillar Framework** | Original analytical model developed in the thesis for evaluating CSR communication governance |
| **Communication Chasm** | The 26-point gap in local language usage between Chhattisgarh (80%) and Jharkhand (54%) |
| **Betterment of Society** | Improvement of societal conditions through CSR initiatives — the thesis's core concept |
| **CG** | Chhattisgarh — Indian state, primary study region |
| **JH** | Jharkhand — Indian state, comparative study region |
| **KTUJMC** | Kushabhau Thakre University of Journalism and Mass Communication — degree-granting institution |
| **Mixed Methods** | Research approach combining quantitative surveys and qualitative interviews |
| **Stakeholder Engagement** | Process of involving parties affected by corporate decisions |

## Technical Terms

| Term | Definition |
|------|-----------|
| **Glassmorphism** | UI design style using frosted glass effects (backdrop-filter: blur) |
| **Scroll Snap** | CSS feature that locks scroll position to defined points |
| **Design Token** | Named CSS custom property representing a design value |
| **BEM-lite** | Simplified Block-Element-Modifier CSS naming convention |
| **IntersectionObserver** | Browser API that detects when elements enter/exit viewport |
| **Breathing Glow** | Continuous pulsing box-shadow animation on accent borders |
| **Slide Badge** | Corner badge showing slide number with dropdown navigation |
