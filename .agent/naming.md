# Naming Conventions

## Files
- **HTML pages**: `kebab-case.html` (e.g., `research-areas.html`, `phd-research.html`)
- **CSS files**: `kebab-case.css` (e.g., `dark-mode.css`, `slider-styles.css`)
- **JS files**: `kebab-case.js` (e.g., `publication-filter.js`, `slide-number.js`)
- **JSON data**: `kebab-case.json` (e.g., `publications.json`)
- **Images**: `kebab-case.ext` (e.g., `profile-photo.jpg`, `five-pillar-framework.png`)
- **Markdown**: `kebab-case.md` (e.g., `coding-rules.md`)

## CSS Classes
- **BEM-lite**: `.block`, `.block__element`, `.block--modifier`
- **Component classes**: `.glass-card`, `.slide-container`, `.chap-nav`
- **State classes**: `.is-visible`, `.is-active`, `.theme-transitioning`
- **Utility classes**: `.grid-2`, `.grid-3`, `.hover-magnify`
- **Theme-specific**: `.neon-text-cg`, `.glow-blue`

## JavaScript
- **Variables**: `camelCase` (e.g., `currentTheme`, `slideContainer`)
- **Constants**: `UPPER_SNAKE_CASE` (e.g., `CHAPTER_MAP`, `MAX_MAGNIFY_WIDTH`)
- **Functions**: `camelCase` (e.g., `getChartColors`, `initLightbox`)
- **DOM IDs**: `kebab-case` (e.g., `slide-1`, `pub-filter-input`)
- **Data attributes**: `kebab-case` (e.g., `data-popup`, `data-gradient`, `data-category`)
- **Event names**: `camelCase` (e.g., `themeChanged`)

## HTML IDs
- Unique, descriptive: `hero-section`, `pub-search`, `contact-form`
- Slide IDs: `slide-1`, `slide-2`, etc.
- Section IDs: `research-statement`, `quick-stats`

## Git
- Branch names: `kebab-case` (e.g., `feature/add-blog`, `fix/dark-mode`)
- Commit types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`
